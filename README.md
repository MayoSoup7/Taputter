# Taputter（たぷったー）Web版

RPGツクールMZ版プラグイン「TapuSNS」をベースに、スマホでいつでも遊べる
Web版として作り直したものです。バックエンドは使わず、HTML / CSS / JavaScript
だけで動作し、GitHub Pages にそのままアップロードして公開できます。

「SNSアプリを再現する」のではなく「たぷが本当にスマホの向こうにいる」と
感じられることを目標にしています。

---

## 🍡 遊び方（ローカルで確認する場合）

**`index.html` をダブルクリックして直接開くだけで動作します。**
返信データ・通知データはすべてJSファイルに埋め込んであるので、
`file://` で開いても（ローカルサーバーを立てなくても）ちゃんと動きます。

もちろん `python3 -m http.server` などのローカルサーバー経由でも、
GitHub Pagesにアップロードしても同じように動作します。

```bash
cd taputter
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

★の2ファイルが、内容を増やしたいときに触るメインのファイルです。
中身はテキストファイルとほぼ同じ形式のまま、JSのバッククォート（`` ` ``）で
囲ってあるだけなので、txtファイルに書くのと同じ感覚で1行追記できます。

## 🧠 DM会話エンジンのしくみ

`js/replies.js` が本体です。プレイヤーの発言から `js/topics.js` の
キーワード辞書で話題を推定し、`data/replies/<話題>.txt` の中から

1. **リアクション**（①まず反応する一言）
2. **自分の話**（②話題を広げる一言）
3. **質問**（③会話を続ける質問）

をそれぞれランダムに1つずつ選んで、LINEのように複数の吹き出しに分けて
時間差で送信します。3段そろう時もあれば、リアクションだけで終わる時も
あり、テンポが単調にならないようにしています。

### 返信パターンを増やしたいとき

`js/replies_data.js` の中の該当する話題のバッククォート内に1行追記するだけでOKです。
コードの変更は一切不要です。3つの引き出し（リアクション/自分の話/質問）
は掛け算で組み合わさるので、1行増やすだけでも組み合わせ数は大きく増えます。

```js
hokkaido: `
## REACTION
（ここに追記）

## TALK
（ここに追記）

## QUESTION
（ここに追記）
`,
```

### 新しい話題を追加したいとき

1. `js/replies_data.js` の `window.TAPU_REPLY_DATA` に新しいキー（話題ID）を
   上のフォーマットで追加する
2. `js/topics.js` の `TOPIC_KEYWORDS` にキーワードを追加
3. `js/topics.js` の `REPLY_TOPIC_FILES` に話題IDを追加（ファイル名は使われませんが、
   話題ID自体の登録として必要です）

これだけで自動的に話題として認識されるようになります。

### プレイヤーの呼び方について

マイページで設定した「呼び方」（呼び捨て・自由入力どちらもOK）が
テキスト内の `{name}` という文字列に自動で差し込まれます。すべての行に
入れる必要はなく、一部の行にだけ入れておくことで「たまに名前を呼ぶ」
自然な頻度になっています。

## 🔥 通知（バズ・炎上）のしくみ

`js/notifications.js` が担当しています。投稿するたびに以下の確率で
判定され、該当するパターンが `data/notifications/` 内のtxtからランダムに
選ばれ、時間差で通知タブに届きます。

| 判定 | 確率 | 内容 |
|---|---|---|
| 何も起きない | 60% | - |
| ちょっと反応 | 20% | `minor.txt` から1件 |
| バズる | 12% | `buzz.txt` から1ブロック（複数件が連続で届く） |
| 炎上する | 8% | `enjou.txt` から1ブロック（大げさ＆カオス方向、最後はオチで収束） |

確率を変えたいときは `js/notifications.js` 内の `PROBS` を編集してください。
`js/notify_data.js` の `buzz` / `enjou` / `minor` に `{user}` と書いておくと、
`usernames` からランダムな名前に自動で差し替わります。バッククォートの中に
行を追記するだけで新しいネタを増やせます。

## 📱 自動ツイート・突然DMについて

`js/engagement.js` が担当しています。

- **自動ツイート**：アプリを開いている間、4分ごとに約18%の確率で
  `js/notify_data.js` の `TAPU_POSTS_DATA` からランダムに1件、たぷが自分で
  ツイートします。通知タブにも「たぷたぷぷ がツイートしました」が届きます。
- **突然DM**：前回たぷからDMが届いてから現実時間で6〜24時間
  （ランダム）経過した状態でアプリを開くと、約70%の確率でたぷの方
  から話しかけてくるDMが届きます。朝・昼・夕方・夜で挨拶の内容が
  変わります（`SURPRISE_DM_GREETINGS` を編集すれば増やせます）。

## 💾 セーブデータについて

バックエンドを持たない静的サイトのため、プレイデータは**そのブラウザの
localStorage**に保存されます。別の端末やブラウザ、シークレットモードでは
引き継がれません。ヘッダー右上の⚙️ボタンからいつでもリセットできます
（開発中の動作確認にも便利です）。

---

## 🔊 効果音（SE）について

`js/sound.js` が担当しています。MZ版で使われていたSE名をそのままファイル名
として使う方式です。現在組み込み済みなのは以下の2つです。

| タイミング | ファイル |
|---|---|
| 投稿を送信した時 | `assets/se/Book2.ogg` |
| 投稿にいいねした時 | `assets/se/Bell3.ogg` |

DM送信音（`Book1`）やリプライ送信音（`Decision3`）など、MZ版の他のSEを
追加したい場合は `assets/se/` にファイルを置いて、鳴らしたい場所で
`window.TapuSound.play('ファイル名（拡張子なし）')` を呼ぶだけです。

## 🖼 キャラクターアイコンについて

現在アイコン画像が設定済みのキャラクター：たぷ、サダ、ニキ、カオル、
どこぞ、まぬ、まよ。画像は `assets/img/` に置き、`js/config.js` の
`CHARACTERS` オブジェクトの該当キャラに `icon: 'assets/img/ファイル名'` を
追加すると反映されます（アイコン未設定のキャラは自動で色付き丸＋頭文字に
なります）。

## 🎙 ボイスDMについて

DMでは、たまにテキストの代わりに「再生できそうな」ボイスメッセージ風の
吹き出しが届きます（`js/engagement.js` の `VOICE_DM_CHANCE` で頻度調整可）。
タップすると波形が揺れてSEが鳴り、`assets/voice/` に対応する音声ファイル
（`voice_01.mp3` など）を置いておけば実際に再生されます。ファイルが無くても
タップ演出とキャプション表示だけは動作するので、音声は後から追加できます。

セリフの中身は `js/notify_data.js` の `window.TAPU_VOICE_LINES` にあります。
`caption`（吹き出し下の説明文）と `file`（対応する音声ファイル名）を
セットで管理しているので、音声を用意したら該当ファイル名で
`assets/voice/` に置くだけでOKです。

## 💬 DMモードについて

DM画面上部のピルボタンで、たぷの返信スタイルを切り替えられます。

| モード | 中身 |
|---|---|
| 💬 雑談 | いつもの話題判定＋組み合わせ会話エンジン（デフォルト） |
| 💯 全肯定 | 何を言っても全力で肯定してくれる |
| 📣 応援 | とにかく背中を押してくれる |
| 💕 甘々 | 距離感が近くて甘い、恋人っぽいモード |
| 🧸 相談 | 聞き役に徹してじっくり寄り添ってくれる |
| 😏 煽り | ちょっと生意気に煽ってくる（愛はある） |
| 😼 メスガキ | 生意気で小悪魔っぽいけど、根は優しい |
| 😤 ツンデレ | 素直になれないけど好意はダダ漏れ |
| 👑 お嬢様 | 優雅に振る舞おうとして道産子の本性がすぐバレる |

雑談モード以外は話題判定をせず、`js/replies_data.js` の
`MODE_◯◯_LINES`（例: `MODE_ZENTEI_LINES`）からランダムに1〜2個選んで
返します。行を追加するだけで増やせます。
新しいモードを追加したい場合は、同じ形で配列を1つ追加し、
`js/replies.js` の `generateForMode()` 内の `map` と、
`index.html` の `#tsns-dm-mode-bar` にボタンを1つ足せばOKです。

## 🎙 ボイスDMの時間帯について

`js/notify_data.js` の `TAPU_VOICE_LINES` は `general` / `morning` / `night`
の3つに分かれています。

- `morning`：5時〜10時のみ選ばれる（おはよう系）
- `night`：20時以降 or 深夜5時まで のみ選ばれる（おやすみ系）
- `general`：いつでも選ばれる

さらに `mode: 'amaama'` のようにタグを付けておくと、甘々モードのDM中は
そのセリフが優先的に選ばれやすくなります（`js/voice.js` の `pickLine()`）。

## 🚀 GitHub Pagesへのアップロード方法

1. GitHubで新しいリポジトリを作成する
2. `taputter` フォルダの中身（index.html, css/, js/, data/, assets/ など）を
   そのままリポジトリのルートにアップロードする
3. リポジトリの `Settings → Pages` を開く
4. 「Source」で `Deploy from a branch` を選び、ブランチを `main`、
   フォルダを `/ (root)` に設定して保存する
5. 数分後に `https://ユーザー名.github.io/リポジトリ名/` でアクセスできる
